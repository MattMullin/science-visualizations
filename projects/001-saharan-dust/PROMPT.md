# Reusable Codex prompt: model dust as an atlas animation

Create a 15–25-second scientific animation of near-surface dust over a chosen
region and 72-hour period. Use a real, citable atmospheric dataset. Record its
provider, version or retrieval timestamp, units, spatial and temporal
resolution, exact request, license, and limitations. Validate missing values,
time alignment, units and physical range before rendering. Use a geographic
basemap with attribution. Distinguish forecasts from observations in every
caption. Export a 1280×720 H.264 MP4 and a thumbnail; store large media outside
Git. Package a reproducible script, frozen small input snapshot, manifest,
README, scientific caveats, demo link if practical, and a draft X caption.
Open a review pull request with test results. Never merge, deploy publicly, or
publish to X without explicit human approval.
