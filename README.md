# Science Visualizations

Open-source science visualization atlas for a planned 180-day series. This repository contains the reusable rendering engine, gallery builder, validation, and review workflow scaffolding. Project 001 (Saharan Dust) is being prepared in a review branch and will not appear in the public gallery until it is approved and merged.

The production scheduler and credentials are kept private. See the project pull request for the frozen scientific dataset, video preview, thumbnail, source code, attribution, and reproduction instructions.
